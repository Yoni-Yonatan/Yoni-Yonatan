### 👨‍💻 About Me

<img align="right" alt="Coding Animation" width="340" src="https://raw.githubusercontent.com/devSouvik/devSouvik/master/gif3.gif">

I am a **19-year-old Full-Stack Software Engineer** and cloud infrastructure architect based in **Addis Ababa, Ethiopia** 🇪🇹. I am the **Founder and Lead Developer of [lewagene.net](https://lewagene.net)**, a high-speed cloud storage platform. Driven by a relentless passion for system design and daily self-improvement, I specialize in building secure, scalable, and resilient web ecosystems.

- ☁️ **Founder @ [lewagene.net](https://lewagene.net):** Architecting a lightning-fast cloud storage platform connecting multiple cloud object storage services with optimized backend APIs.
- ⚡ **Full-Stack & Edge Engineering:** Building production applications using the **PERN Stack (PostgreSQL, Express.js, React, Node.js)** alongside modern frameworks including **Next.js, NestJS, Hono.js, and Tailwind CSS**.
- 🏗️ **System Design & Architecture:** Designing scalable multi-tier architectures, including **Online Educational Systems (LMS)**, real-time data pipelines, and secure cloud apps.
- 🚀 **Cloud & Deployment Infrastructure:** Managing production deployments across **Cloudflare, Vercel, Docker, Git, and cPanel**.
- 🛡️ **Certifications:**
  - **Software Engineering Certification** — *IBM*
  - **Google Cybersecurity Certificate** — *Google*
- 🤝 **Engineering Culture & Personal Skills:** Strong technical **communication**, rapid **adaptability** to new codebases, and proactive **team/open-source contribution**.
